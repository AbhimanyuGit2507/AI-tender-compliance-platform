### Technology 1: Parallel Review Board Swarm (3.8s Execution)

Instead of a sequential LangGraph chain that takes 60 seconds and repeats context 5 times, BidKaro deploys a **Parallel Specialized Swarm**:

```python
# app/services/swarm_review.py
import asyncio
from app.services.llm_router import get_llm_router, LLMTier

async def run_parallel_review_board(tender_context: str, boq_summary: str, company_profile: dict):
    router = get_llm_router()
    
    # 4 Specialist Prompts execute concurrently via asyncio.gather
    legal_task = router.generate(
        tier=LLMTier.TIER_2_STRUCTURED,
        prompt=f"LEGAL LENS: Audit debarment, joint venture liability, EMD forfeiture, and liquidated damages in:\n{tender_context}",
        operation_type="swarm_legal"
    )
    qs_task = router.generate(
        tier=LLMTier.TIER_2_STRUCTURED,
        prompt=f"QUANTITY SURVEYOR LENS: Audit BOQ quantities, rate non-conformities, and Cover 1 price leak risks:\n{boq_summary}",
        operation_type="swarm_qs"
    )
    tech_task = router.generate(
        tier=LLMTier.TIER_2_STRUCTURED,
        prompt=f"TECHNICAL SPEC LENS: Audit equipment mobilization, similar work thresholds, and ISO codes:\n{tender_context}",
        operation_type="swarm_tech"
    )
    red_team_task = router.generate(
        tier=LLMTier.TIER_2_STRUCTURED,
        prompt=f"ADVERSARIAL RED-TEAM LENS: Act as a rival bidder or strict tendering authority. Find the 3 most likely grounds to DISQUALIFY this contractor ({company_profile}):\n{tender_context}",
        operation_type="swarm_red_team"
    )

    legal_rep, qs_rep, tech_rep, red_rep = await asyncio.gather(
        legal_task, qs_task, tech_task, red_team_task
    )

    # 5th Executive Arbiter Synthesizes into Actionable Verdict
    arbiter_prompt = f"""Synthesize the 4 specialist audits into an authoritative tender verdict matrix:
    - LEGAL FINDINGS: {legal_rep.text}
    - QS & BOQ FINDINGS: {qs_rep.text}
    - TECHNICAL SPEC FINDINGS: {tech_rep.text}
    - RED-TEAM DISQUALIFICATION GROUNDS: {red_rep.text}
    
    Output structured JSON with confidence score (0-100), critical blockers, and action checklist."""
    
    verdict = await router.generate(
        tier=LLMTier.TIER_3_REASONING,
        prompt=arbiter_prompt,
        operation_type="swarm_arbitration"
    )
    return verdict.json()
```
- **Execution Time**: ~3.8 seconds total.
- **Cost**: ₹4.80 – ₹6.00 total.
- **Impact**: Provides contractors the exact depth of a 5-person senior procurement consulting board in seconds.

### Technology 2: Selective Gemini Flash-Lite Visual Drawing Intelligence

Most tender pages (90–95%) are standard legal clauses and tables cleanly parsed by PyMuPDF at ₹0 cost. Only technical drawings, site cross-sections, alignment plans, and complex structural schedules require multimodal vision:

```python
# app/services/visual_drawing_detector.py
import fitz  # PyMuPDF

def identify_visual_drawing_pages(pdf_bytes: bytes) -> list[int]:
    """Detects pages that contain architectural drawings, structural layouts, or visual maps."""
    doc = fitz.open(stream=pdf_bytes, filetype="pdf")
    drawing_pages = []
    
    for page_idx, page in enumerate(doc):
        drawings = page.get_drawings()  # Vector lines, CAD paths, curves
        images = page.get_images()
        text_len = len(page.get_text().strip())
        rect = page.rect
        is_landscape = (rect.width > rect.height)
        
        # Heuristic: High vector path density + low text length or landscape engineering sheet
        if (len(drawings) > 40 and text_len < 400) or (is_landscape and len(drawings) > 20) or len(images) > 3:
            drawing_pages.append(page_idx)
            
    return drawing_pages
```
- When a drawing page is detected, PyMuPDF renders it to high-res PNG in memory and streams it to **Gemini 2.0 Flash-Lite Vision API**.
- The vision prompt extracts:
  1. Title block: Drawing number, revision date, approving authority.
  2. Structural schedule: Rebar grades (Fe 500D), concrete design mixes (M35/M40), pipe wall thicknesses.
  3. Dimension notes and tolerance guidelines.
- **Cost**: ₹0.15 per visual page × ~12 pages = **₹1.80** total.

### Technology 3: Precedence-Aware Statutory Clause Graph (SQL CTEs)

Indian public procurement has strict statutory hierarchy:
$$\text{Addendum / Corrigenda} \succ \text{SCC (Special Conditions)} \succ \text{GCC (General Conditions)} \succ \text{CPWD Works Manual / GFR 2017}$$

Instead of an external graph database, PostgreSQL executes multi-hop statutory precedence in **< 2ms** using recursive Common Table Expressions:

```sql
-- Resolving clause override precedence in pure PostgreSQL 16
WITH RECURSIVE clause_hierarchy AS (
    -- Anchor: Find the targeted clause in GCC
    SELECT 
        id, clause_ref, title, exact_snippet, category, 
        superseded_by, 1 AS depth
    FROM tender_requirements
    WHERE tender_id = :tender_id AND clause_ref = :target_clause
    
    UNION ALL
    
    -- Recursive Step: Follow override pointers (GCC -> SCC -> Corrigenda)
    SELECT 
        tr.id, tr.clause_ref, tr.title, tr.exact_snippet, tr.category,
        tr.superseded_by, ch.depth + 1
    FROM tender_requirements tr
    JOIN clause_hierarchy ch ON tr.id = ch.superseded_by
)
SELECT * FROM clause_hierarchy ORDER BY depth DESC LIMIT 1;
```
- When a tender has 3 corrigenda that modify defect liability from 12 months to 36 months, the query instantly yields the authoritative active rule and cites every superseded historical clause.

### Technology 4: 10,000-Run Monte Carlo Price-to-Win (PTW) Simulator

In Indian tenders, bidding too high causes bid loss (not L1); bidding too low triggers the **Abnormally Low Bid (ALB)** trap or unviable contract execution.

BidKaro integrates a high-speed NumPy Monte Carlo engine:
1. Inputs: Estimated tender value, departmental Schedule of Rates (DSR/SoR), contractor's baseline direct cost (materials, labor, plant, overheads).
2. Historical distribution of L1 winning rebates for the specific authority (e.g., CPWD Delhi: $-14.2\% \pm 3.1\%$, UP PWD: $-18.5\% \pm 4.2\%$).
3. Simulates 10,000 competing bid scenarios across 5 to 12 competitor archetypes (Aggressive, Conservative, Incumbent).
4. Outputs:
   - **Optimal Bid Value**: Maximum contractor EBITDA margin subject to $\ge 75\%$ probability of winning L1.
   - **ALB Danger Zone**: The exact price threshold below which additional performance security (bank guarantee) is mandated by CPWD Manual Section 17.5.
- **Compute Time**: 42 milliseconds on CPU. **Cost: ₹0.00**.
